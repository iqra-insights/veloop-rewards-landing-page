# VELOOP Rewards - Landing Page

Responsive landing page for VELOOP Rewards, a rewards and engagement platform that is still in development.
Built with plain HTML, CSS and JavaScript (single file, no build step).

## Features
- Mobile-first responsive layout with a mobile menu
- Ways-to-earn cards with filters and detail pop-ups
- Interactive demo (streak, XP, level, lucky spin) - illustrative only
- Wallet and withdrawal lifecycle explainer
- FAQ, roadmap, brand/partner section, waitlist form (demo only)
- Google Play / App Store badges open a "coming soon" pop-up because the apps are not released

## Run locally
Open `index.html` in a browser, or in VS Code use the Live Server extension (right-click `index.html` -> Open with Live Server).

## Deploy
Import this repository in Vercel (Framework preset: Other). No build command is needed.

## Data note
No real user numbers, earnings, ratings or testimonials are shown. All sample values are illustrative.
